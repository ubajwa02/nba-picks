### The posted strategy ("leans", source `props_v1`, since 2026-10-26)

1. `predict` prices every DraftKings (via ESPN) and bet365 prop for pts, reb, ast, fg3m with props-v1: expected minutes (recency half-life 3 games, previous seasons x0.1) x per-minute rate (half-life 10-40 games, previous seasons x0.5-0.75, shrunk to a league prior) x opponent factor, negative-binomial outcome. No calibration layer and no market blend on props.
2. `qualify.judge` gives each side a decision (`eligible` / `watch` / `hold` / `reject`) with EV >= 5% as the prop threshold.
3. `leans.pick_leans` then posts up to 6 sides a day ranked by **model win probability**, requiring p >= 0.60, decimal >= 1.50, >= 5 recent games, no milestone/side-unverified flag, one per player, two per game. **EV is not part of the rule**, and a side rejected for "EV below 5%" still qualifies (soft reason).
4. Parlays (2 a day, 2 legs) and one lotto (3-5 legs) are built from a wider pool (p >= 0.50, decimal >= 1.15), always posted, labelled research, 1u each.
5. Grading: `track.grade` / `settle.py` from ESPN final scores and box scores; a prop whose player has no box row in a final game is void.

Earlier posted sources in the same ledger are different strategies: `model_lean` (game markets, 2026-10-20/21) and `split_card` (props, 2026-10-21..23). No slate was posted on 2026-10-24/25 (no pipeline runs those days).

## Known issues at this baseline

- Injury holds are dropped from the decision reason when EV is below the threshold (`qualify.judge` returns before the hold list is written), so `leans._clean_decision` treats the side as clean. Posted: Ty Jerome o2.5 reb (2026-10-31, Day-To-Day, did not play, void) and Aaron Nesmith u3.5 reb (2026-11-01, Day-To-Day).
- `pick_leans` does not re-check quote age at posting; 5 leans were posted on quotes 150-176 min old (rule: 120 min).
- 28 of 42 props_v1 leans were rejected by the system's own qualification at posting; 9 had negative model EV; 7 cleared 5%.
- The weekly `nba-research` workflow has never run (0 runs), so no challenger, forward calibration check or automatic demotion has executed live.
